# English experiment Notebooks

The [English lab](https://walkinglabs.github.io/hands-on-modern-rl/en/labs/) opens English explanations, exercises and references for all 22 experiments. The ten self-contained chapter Notebooks are stored here. The twelve Studio companions already have English originals in the parent directory.

The ten chapter Notebooks use the same training code and budgets as their Chinese counterparts. Their English versions were executed in fresh local CPU kernels; [execution evidence](../../chapter-notebooks/validation.en.json) records file hashes, timings and actual results. Colab, ModelScope and the native GPU simulators retain their separately documented verification limits.

Edit the English teaching text in `code/chapter-notebooks/en/`, then regenerate the counterparts with `python scripts/build_localized_notebooks.py`. Existing parent-directory URLs remain available for compatibility.
